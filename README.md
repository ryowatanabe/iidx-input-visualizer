# IIDX Input Visualizer（プロトタイプ）

Windows PCで接続したbeatmania IIDXコントローラーの入力をブラウザに表示し、鍵盤の押下とターンテーブルの操作を数えるプロトタイプです。

公開版: [IIDX Input Visualizer](https://ryowatanabe.github.io/iidx-input-visualizer/)

## ローカルで試す

`index.html` をChromeまたはEdgeで直接開きます。コントローラーのボタンを押してブラウザに認識させてください。入力診断を開くと、ブラウザが認識したボタンと軸の番号・値を確認できます。計測中はこのタブを表示したままにしてください。

ビルドや依存パッケージのインストールは不要です。ブラウザでGamepad APIが利用できない場合は、ローカルHTTPサーバーを立てて `http://localhost` で開いてください。

## 仕様

- 初期対応機種: KONAMI beatmania IIDX 専用コントローラ。ブラウザのボタン0～6を鍵盤1～7、軸0をターンテーブルとして扱います。
- 鍵盤は押し始めを1回と数えます。ターンテーブルは回し始め、停止前の方向転換を各1回と数えます。
- ターンテーブルはX軸が1刻み（約0.008）変化した時点で回転開始・方向転換を判定します。
- 1P、2P、DPの配置を切り替えられます。DPでは異なる2台を割り当てます。
- 内部カウントは1P・2Pの各鍵盤とターンテーブルごとに保持し、画面には全体の合計を表示します。カウントと表示設定はブラウザのローカルストレージに保存します。
- 非表示のタブでの連続計測は保証しません。タブが非表示になった場合は計測を一時停止します。

## 実機確認で調整する項目

`app.js` の `PROFILES` に機種ごとのボタン・軸対応と判定閾値を定義しています。実機の入力診断を見て、ブラウザ上での対応、軸の折り返し位置、ノイズ、停止時間を確認してください。
